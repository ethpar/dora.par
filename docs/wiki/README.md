# Dora Wiki Documentation

This directory contains the source files for the Dora Block Explorer wiki.

## Structure

- `Home.md` - Main wiki landing page with navigation
- `_Sidebar.md` - Sidebar navigation (automatically included by GitHub Wiki)
- `_Footer.md` - Footer content (automatically included by GitHub Wiki)
- `Getting-Started/` - Guides for new users
- `Architecture/` - System architecture documentation
- `Development/` - Developer documentation
- `Operations/` - Deployment and operations guides
- `References/` - API references and technical details

## Contributing

To contribute to the wiki:

1. Edit the appropriate Markdown (.md) files
2. Follow the existing style and formatting
3. Submit a pull request with your changes

## Viewing Locally

To view the wiki locally, you can use any Markdown viewer or serve it using a static site generator like [MkDocs](https://www.mkdocs.org/) or [Docsify](https://docsify.js.org/).
